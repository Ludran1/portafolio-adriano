## Instalación y Desarrollo

1.  Clonar el repositorio:

    ```bash
    git clone https://github.com/Ludran1/portafolio-adriano.git
    cd portafolio-adriano
    ```

2.  Instalar dependencias:

    ```bash
    npm install
    ```

3.  Correr el servidor de desarrollo:
    ```bash
    npm run dev
    ```
